# Onboarding de cliente em 15 minutos

Este roteiro serve para implantar um novo estúdio rapidamente.

## Minuto 0-2: acesso

1. Criar usuário admin no Supabase Auth.
2. Definir `app_metadata.role = "admin"`.
3. Entrar no painel com o cliente.

## Minuto 2-5: identidade

1. Abrir **Operação**.
2. Configurar nome comercial.
3. Configurar WhatsApp principal.
4. Escolher cores do link público.
5. Salvar marca pública.

## Minuto 5-8: operação

1. Configurar abertura, fechamento e intervalo da agenda.
2. Criar os principais serviços.
3. Informar preço, duração e capacidade.

## Minuto 8-11: equipe

1. Cadastrar profissionais.
2. Definir horários individuais se houver.
3. Definir comissão.
4. Vincular serviços atendidos.

## Minuto 11-13: teste público

1. Copiar link público.
2. Criar uma reserva teste.
3. Confirmar se a reserva apareceu em **Agenda**.
4. Confirmar a reserva.

## Minuto 13-15: rotina

1. Mostrar **Automação** para lembretes e recuperação.
2. Mostrar **Financeiro** para comissões e fechamento.
3. Mostrar o checklist do Dashboard.

## Frase de orientação para o cliente

"No dia a dia, você começa pela Agenda, usa Automação para confirmar e lembrar clientes, e fecha a semana ou o mês no Financeiro."
